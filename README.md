# CareerMate

CareerMate is a local-first, open-source AI-powered job search and application assistant.

## Features

- Read and understand your CV
- Search relevant job opportunities
- Remove duplicate jobs
- Match jobs against your CV
- Explain job compatibility
- Generate tailored cover letters
- Prepare application answers
- Assist with application forms
- Keep personal data local
- Require human confirmation before final submission

## Architecture

- Backend: Python + FastAPI
- Frontend: React + TypeScript
- Storage: Local JSON files
- Browser automation: Playwright
- AI: Local LLM

## Philosophy

CareerMate is designed for personal local use. Sensitive information stays on the user's machine whenever possible.
